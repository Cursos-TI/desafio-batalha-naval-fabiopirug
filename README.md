# 🚢 Battleship Game (Batalha Naval)

This is a text-based Battleship game running directly in the terminal. I developed this project as part of my Analysis and Systems Development college degree to practice advanced logic, arrays, and conditional structures.

## 🚀 Technologies Used
* **C Language** (Linguagem C)
* VS Code

## 🛠️ How to Play
1. Open the project in a C compiler or VS Code.
2. Run the application.
3. Input the coordinates in the terminal to target and sink the enemy ships!
